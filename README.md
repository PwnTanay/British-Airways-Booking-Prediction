# British Airways Booking Prediction

## Project Overview
This project uses Machine Learning to predict whether a customer will complete a booking for British Airways based on customer behavior and travel-related features.

## Technologies Used
Python
Pandas
Scikit-learn
Matplotlib
Random Forest Classifier

## Machine Learning Workflow
Data Cleaning
Feature Encoding
Train-Test Split
Random Forest Model Training
Model Evaluation
Feature Importance Visualization

## Model Performance
Accuracy: 85.59%

## Key Insights
The most important factors influencing booking completion were:
Purchase lead time
Flight hour
Length of stay
Number of passengers
Flight duration

`British_Airways.ipynb` → Main notebook
